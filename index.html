Projects

rupert-ai

A Python-based AI coding agent, built up over several months from a basic CLI tool into a full FastAPI HTTP service. Includes API key authentication, request logging, and SQLite-backed conversation history so context survives server restarts. Uses an agent loop pattern with function calling to read files, write files, run Python, and search the web with a DuckDuckGo search library.

pygame-asteroids

A classic Asteroids clone built with Python and pygame. Features a full state machine (start/playing/game-over), a lives system with respawn and invulnerability, asteroid splitting, polygon rendering, sound effects, and a size-based scoring system where smaller asteroids are worth more points.
